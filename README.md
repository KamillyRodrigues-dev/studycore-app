# 📚 StudyCore — Plataforma de Organização Estutantil

O **StudyCore** é uma solução web desenvolvida para ajudar estudantes a organizarem melhor sua rotina acadêmica, tarefas e cronogramas de estudos de forma prática e intuitiva.

> 🎓 Projeto acadêmico desenvolvido para a disciplina de **Desenvolvimento Web** (2º Semestre).

---

## 📌 Sobre o Projeto

O objetivo deste projeto é aplicar os conceitos fundamentais do desenvolvimento web para construir a estrutura e a interface visual de uma plataforma de organização de estudos.

 Conforme orientado pelo professor da disciplina, a implementação foi realizada utilizando **apenas HTML5 e CSS Inline**, exercitando a base estrutural de páginas web, posicionamento de elementos e navegação entre páginas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação de conteúdo, listas, formulários, tabelas e hiperlinks.
- **CSS3 (Inline):** Estilização de elementos, cores, tipografia, alinhamentos e conceitos de `position`.
